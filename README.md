Smart Accident Management System

Smart Accident Management System (SAMS) is a **Python Full Stack web application** designed to simplify accident assessment and management. The system uses **Django, Machine Learning, OCR, and database integration** to analyze accident-related information.

Key Features

* Upload accident images and assess vehicle damage using Machine Learning.
* Detect and extract vehicle number plates using OCR.
* Retrieve vehicle and insurance information from the database.
* Calculate estimated damage costs and insurance coverage.
* Determine the payable amount after insurance deduction.
* Locate nearby hospitals and vehicles using map integration.
* Provide a centralized platform for managing accident-related information.

Technologies Used:

1 Python 
2 Django 
3 Machine Learning
3 OCR 
4 HTML
5 CSS 
6 JavaScript
7 SQL 
8 Google Maps API

 Project Purpose:

The project aims to reduce manual effort in accident assessment and provide faster access to vehicle, insurance, damage, and emergency-service information through a single web-based platform.
